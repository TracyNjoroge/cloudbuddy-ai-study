# CloudBuddy 

**Your AZ-900 Study Buddy**

CloudBuddy is a beginner-friendly study dashboard designed to help learners prepare for the Microsoft Azure Fundamentals (AZ-900) certification. It brings study notes, interactive practice questions, and prepared study-assistant responses together in one place.

## Problem

Preparing for AZ-900 can feel overwhelming when learners need to move between study materials, practice questions, and explanations. CloudBuddy aims to make revision more organized and approachable through a simple, interactive learning experience.

## Solution

CloudBuddy provides a single place to review key Azure concepts and practise applying what you've learned.

### Features

- **Interactive AZ-900 quiz:** Answer multiple-choice questions, submit responses, review feedback and explanations, track progress, and see your final score.
- **Study topics:** Explore beginner-friendly notes, key concepts, and practical examples across three AZ-900 topic areas.
- **Prepared study assistant:** Ask questions and receive responses based on locally prepared study content, with a helpful notice when a question isn't covered.
- **Responsive interface:** Navigate the dashboard on desktop and mobile-sized screens.

## Topics Covered

- Azure cloud concepts
- Azure architecture and services
- Azure management and governance

## Built With

- Bolt.new for AI-assisted development and rapid prototyping
- React for the user interface
- TypeScript and CSS for application logic and styling

## How to Explore the Demo

1. Open the live demo.
2. Explore the AZ-900 study topics.
3. Start the practice quiz and submit answers to view feedback.
4. Finish the quiz to see your score, then try restarting it.
5. Explore the prepared study assistant.

## AI and Current Limitations

CloudBuddy was developed with AI-assisted tools, including Bolt.new. Its current study-assistant responses are prepared locally; they are not generated by a live AI model.

The prototype currently includes five quiz questions and a limited set of prepared study topics and responses. Expanding the question bank and study content is a potential future improvement.

## Future Improvements
